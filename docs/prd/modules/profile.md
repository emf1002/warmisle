# 个人中心 — 模块需求

> 关联规则：[业务规则 - 认证规则](../business-rules.md#82-认证规则)（修改密码后 Token 失效）

## 详细功能说明

**功能描述**：成员查看和编辑个人信息、修改密码、退出登录，以及跳转到分类管理和成员管理的入口。

**前置条件**：用户已登录。

**页面结构**：

```
┌─────────────────────────────────┐
│          👨  张三               │  ← 头像 + 姓名
│          管理员                  │  ← 角色标签
│          @zhangsan              │  ← 用户名（仅展示）
├─────────────────────────────────┤
│  📒 账单分类                >   │  ← 跳转入口
│  👨‍👩‍👧 家庭成员               >   │  ← 跳转入口
├─────────────────────────────────┤
│  ✏️  修改个人信息                │  ← 弹出编辑表单
│  🔒 修改密码                    │  ← 弹出修改密码表单
│  🚪 退出登录                    │  ← 二次确认后退出
└─────────────────────────────────┘
```

**桌面端入口**：顶栏右侧头像点击，下拉菜单显示"个人信息"、"修改密码"、"退出登录"。分类和成员管理通过侧边栏直接访问，不出现在下拉菜单中。

**手机端入口**：底部 TabBar"我的"标签，进入个人中心页面。分类管理和成员管理作为页面内列表项跳转。

**主流程 — 修改个人信息**：
1. 用户点击「修改个人信息」
2. 弹出表单，预填当前姓名和头像
3. 用户修改姓名（1-20字符）或从预置 emoji 列表重新选择头像
4. 保存后全局同步更新（记账记录者、待办指派人、评论等关联显示）

**主流程 — 修改密码**：
1. 用户点击「修改密码」
2. 弹出表单：旧密码（必填）+ 新密码（必填，6-32字符）+ 确认新密码（必填）
3. 系统校验：旧密码正确、新密码与确认密码一致、新密码不可与旧密码相同
4. 修改成功后清除 Token，跳转登录页重新登录

**主流程 — 退出登录**：
1. 用户点击「退出登录」
2. 弹出二次确认"确定要退出登录吗？"
3. 确认后清除 Token，跳转登录页

**异常流程**：

| 异常场景 | 处理策略 |
|----------|----------|
| 姓名为空或超长 | 前端拦截，提示"请输入1-20字符的姓名" |
| 旧密码错误 | 后端返回错误，提示"原密码错误" |
| 两次新密码不一致 | 前端拦截，提示"两次输入的密码不一致" |
| 新密码与旧密码相同 | 后端返回错误，提示"新密码不能与旧密码相同" |

## 关联业务规则速查

- 密码规则详见 [BR-A01~BR-A08](../business-rules.md#82-认证规则)
- 修改密码成功后 Token 立即失效（[BR-A07](../business-rules.md#82-认证规则)）
- 姓名 1-20 字符，密码 6-32 字符（[字段约束](../business-rules.md#811-字段约束)）
