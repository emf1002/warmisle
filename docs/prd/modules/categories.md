# 分类管理 — 模块需求

> 关联规则：[业务规则 - 收支类型规则](../business-rules.md#84-收支类型规则)、[业务规则 - 删除规则](../business-rules.md#86-删除规则)、[业务规则 - 预置数据规则](../business-rules.md#812-预置数据规则)

## 用户故事

| ID | 角色 | 动作 | 价值 | 验收标准 |
|----|------|------|------|----------|
| C-01 | 成员 | 查看分类列表 | 快速选择记账分类 | 1. 按收入/支出分组展示<br>2. 显示图标和名称 |
| C-02 | 管理员 | 添加自定义分类 | 适应家庭个性化需求 | 1. 可创建收入或支出分类<br>2. 可设图标和排序<br>3. 同类型下不可创建同名分类 |
| C-03 | 管理员 | 编辑分类 | 修正分类信息 | 1. 可修改名称、图标、排序、type<br>2. 修改 type 后关联的记账记录收支方向同步变化 |
| C-04 | 管理员 | 删除分类 | 清理无用分类 | 1. 无关联记录时软删除<br>2. 有关联记录时拒绝并提示数量 |
| C-05 | 成员 | 使用预置分类 | 开箱即用 | 1. 系统预置常用分类（见下表）<br>2. 预置分类管理员可编辑和删除 |

## 关联业务规则速查

- 分类 type 变更影响：修改分类 type 后，关联记账记录的收支方向**实时同步变化**，详见 [BR-T03/BR-T04](../business-rules.md#84-收支类型规则)
- 分类名称约束：1-20 字符，同类型下唯一（[字段约束](../business-rules.md#811-字段约束)）
- 预置数据规则详见 [BR-PD01/BR-PD02](../business-rules.md#812-预置数据规则)
