# 网盘备份 — 模块需求

> 关联规则：[业务规则 - 备份规则](../business-rules.md#813-备份规则)

## 用户故事

| ID | 角色 | 动作 | 价值 | 验收标准 |
|----|------|------|------|----------|
| B-01 | 管理员 | 配置阿里云盘 OAuth2 授权 | 打通暖屿与阿里云盘的连接 | 1. 在备份设置页面填写 app_id、app_secret<br>2. 系统根据配置生成授权链接<br>3. 管理员点击链接跳转阿里云盘授权页面<br>4. 用户同意授权后回调，系统自动换取 access_token 和 refresh_token<br>5. 授权成功后显示"已授权"状态和授权账号信息<br>6. 支持重新授权（更新 token）和撤销授权 |
| B-02 | 管理员 | 手动触发数据库备份 | 随时将数据备份到云盘 | 1. 在备份管理页面点击「立即备份」按钮<br>2. 系统检查阿里云盘授权状态，未授权则提示先授权<br>3. 系统复制当前 SQLite 数据库文件，执行完整性检查（PRAGMA integrity_check）<br>4. 检查通过后上传到阿里云盘指定目录（默认 /warmisle-backups/）<br>5. 备份文件名格式：warmisle_backup_YYYYMMDD_HHmmss.db<br>6. 上传完成后显示备份成功提示，记录备份历史<br>7. 上传失败显示错误信息和重试建议 |
| B-03 | 管理员 | 配置定时自动备份 | 无需手动操作，定期自动保护数据 | 1. 在备份设置页面配置自动备份开关（默认关闭）<br>2. 配置执行时间（支持 cron 表达式或简单时间选择，如每天凌晨 2:00）<br>3. 配置备份保留天数（默认 30 天）<br>4. 系统定时执行备份流程（与手动备份一致）<br>5. 自动备份失败时记录错误日志，下次执行时重试<br>6. 系统按保留天数自动清理阿里云盘上的过期备份文件 |
| B-04 | 管理员 | 查看网盘备份文件列表 | 了解备份历史和状态 | 1. 在备份管理页面查看云盘上的备份文件列表<br>2. 每个备份文件显示：文件名、文件大小、备份时间（从云盘读取）<br>3. 列表按备份时间倒序排列<br>4. 显示本地备份历史记录（时间、大小、状态：成功/失败/恢复中）<br>5. 失败的备份记录显示失败原因 |
| B-05 | 管理员 | 从网盘恢复备份 | 在数据丢失或迁移时恢复系统 | 1. 在备份列表中选择一个备份文件<br>2. 点击「恢复到此备份」按钮<br>3. 系统弹出二次确认：⚠️ 警告提示"恢复将覆盖当前数据库，此操作不可逆！建议先手动备份当前数据。"<br>4. 用户确认后，系统下载选中备份文件到本地临时目录<br>5. 系统校验下载文件的完整性（对比云盘文件大小）<br>6. 校验通过后替换当前 SQLite 数据库文件<br>7. 系统自动重启服务，加载新数据库<br>8. 恢复完成后跳转登录页，用户重新登录 |

## 详细功能说明

**功能描述**：将暖屿 SQLite 数据库文件备份到阿里云盘，支持手动备份、定时自动备份、备份列表查看、从网盘恢复备份。仅管理员可操作。

**前置条件**：用户为管理员角色，已在阿里云盘开放平台注册应用并获取 app_id 和 app_secret。

**技术架构**：

```
┌──────────────────────────────────────────────────┐
│                   Web UI（管理后台）               │
│         授权配置 | 手动备份 | 定时设置 | 备份列表  │
│         恢复操作（含警告+二次确认）                 │
├──────────────────────────────────────────────────┤
│                  网盘接口层（插件化）               │
│    标准接口：Upload / Download / List / Delete    │
├──────────────────┬───────────────────────────────┤
│   阿里云盘实现     │   百度网盘（V2预留）           │
│   OpenAPI SDK     │   ...                        │
└──────────────────┴───────────────────────────────┘
```

**网盘标准接口定义**：

| 方法 | 说明 | 参数 | 返回 |
|------|------|------|------|
| Upload | 上传文件到云盘 | 本地文件路径、云端目录路径 | 云端文件信息(ID、名称、大小) |
| Download | 从云盘下载文件 | 云端文件ID、本地保存路径 | 本地文件路径 |
| List | 列出云盘目录下的文件 | 云端目录路径 | 文件列表(名称、大小、时间) |
| Delete | 删除云盘上的文件 | 云端文件ID | 是否成功 |

**主流程 — OAuth2 授权配置**：

1. 管理员在阿里云盘开放平台注册应用，获取 app_id 和 app_secret
2. 在暖屿备份设置页面填写 app_id、app_secret、redirect_uri
3. 保存后系统生成授权链接（含 client_id、redirect_uri、scope、state）
4. 管理员点击「去授权」跳转阿里云盘授权页面
5. 用户在阿里云盘侧确认授权（需要的 scope：user:base、file:all:read、file:all:write）
6. 阿里云盘回调 redirect_uri，携带 authorization_code
7. 暖屿后端用 code 换取 access_token 和 refresh_token
8. 系统安全存储 token（加密存储于数据库），显示授权账号信息

**主流程 — 手动备份**：

1. 管理员在备份管理页面点击「立即备份」
2. 系统校验阿里云盘授权状态（token 过期则自动用 refresh_token 刷新）
3. 系统复制当前 SQLite 数据库文件到临时目录
4. 对副本执行 `PRAGMA integrity_check`，检查数据库完整性
5. 检查通过后，调用阿里云盘 Upload API，上传到指定目录（默认 `/warmisle-backups/`）
6. 文件命名：`warmisle_backup_20260619_020000.db`
7. 上传成功后：记录本地备份历史、清理过期备份
8. 上传失败记录错误日志，备份历史标记为"失败"

**主流程 — 定时自动备份**：

1. 管理员在备份设置页面开启自动备份
2. 配置执行时间（默认每天凌晨 2:00，支持修改）
3. 配置备份保留天数（默认 30 天，可修改）
4. 后端定时任务在配置时间触发，执行流程与手动备份一致
5. 定时任务每次执行后自动清理过期备份

**主流程 — 查看备份列表**：

1. 管理员进入备份管理页面
2. 页面分两个区域：
   - **云盘备份文件**：调用阿里云盘 List API 获取文件列表
   - **本地备份历史**：从数据库读取备份历史记录
3. 云盘列表为空时显示"云端暂无备份文件"
4. 本地历史为空时显示"暂无备份记录"

**主流程 — 恢复备份**：

1. 管理员在云盘备份文件列表中选择一个备份文件
2. 点击「恢复到此备份」
3. 系统弹出警告对话框（含备份时间、文件大小、操作风险说明）
4. 用户确认后：自动创建紧急备份 → 下载文件 → 校验大小 → 替换数据库 → 重启服务
5. 用户重新登录系统

**恢复失败处理**：

| 异常场景 | 处理策略 |
|----------|----------|
| 下载中断 | 保留当前数据库不变，提示"下载失败，请检查网络后重试" |
| 文件校验不通过 | 不执行替换，提示"备份文件校验失败，可能已损坏" |
| 服务重启失败 | 记录错误日志，提示用户手动重启服务 |
| Token 过期 | 自动使用 refresh_token 刷新，刷新失败则提示重新授权 |

**Token 管理规则**：

| 维度 | 说明 |
|------|------|
| access_token 有效期 | 约 2 小时（阿里云盘官方限定） |
| refresh_token 刷新 | 每次 API 调用前检查，过期则自动刷新 |
| Token 存储 | 加密存储于暖屿数据库中（AES-256-GCM 加密，密钥来自环境变量） |
| 刷新失败处理 | 提示管理员重新授权，备份功能暂停 |
| 撤销授权 | 管理员可在设置中撤销授权，清空本地 token |

**异常流程**：

| 异常场景 | 处理策略 |
|----------|----------|
| 未授权点击备份 | 前端弹窗"请先完成阿里云盘授权" |
| 授权回调 state 不匹配 | 后端拒绝，提示"授权验证失败，请重试" |
| 数据库完整性检查失败 | 不执行上传，提示"数据库完整性检查失败，请检查数据库" |
| 云盘空间不足 | 提示"云盘空间不足，请清理后重试" |
| 网络超时 | 超时时间 5 分钟，超时后提示"网络超时，请重试" |
| 备份文件不存在（恢复时） | 刷新云盘列表，该文件标记"已失效" |
| 非管理员访问备份接口 | 返回 403，提示"权限不足，仅管理员可操作" |

**空状态规则**：

| 场景 | 展示内容 | 引导动作 |
|------|----------|----------|
| 未授权 | "尚未配置阿里云盘授权" | 显示「去配置」按钮 |
| 已授权，无备份 | "云端暂无备份文件，开始第一次备份吧" | 显示「立即备份」按钮 |
| 本地无备份历史 | "暂无备份记录" | 无 |
| 定时备份未开启 | 开关处于关闭状态，显示"自动备份已关闭" | 无 |
