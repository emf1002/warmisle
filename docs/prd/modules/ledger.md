# 记账本 — 模块需求

## 用户故事

| ID | 角色 | 动作 | 价值 | 验收标准 |
|----|------|------|------|----------|
| L-01 | 成员 | 记一笔收支 | 记录每笔花销和收入 | 1. 选择分类→输入金额→选日期→保存<br>2. 收支方向由所选分类的 type 决定（实时引用，不快照）<br>3. 记录者自动设为当前登录用户<br>4. 金额以元输入，存储以分<br>5. 保存后立即出现在列表 |
| L-02 | 成员 | 按月查看账单 | 了解月度收支全貌 | 1. 默认显示当月记录<br>2. 可切换月份（不限制范围），与仪表盘月份切换各自独立不联动<br>3. 顶部显示月度收入/支出/结余（固定在列表顶部，结余为负红色高亮） |
| L-03 | 成员 | 筛选账单 | 快速定位特定记录 | 1. 可按分类筛选<br>2. 可按记录者筛选<br>3. 筛选条件可组合 |
| L-04 | 成员 | 编辑自己的账单 | 修正错误记录 | 1. 只能编辑自己创建的记录<br>2. 修改分类后收支方向随新分类的 type 自动变化<br>3. 记录者不可更改 |
| L-05 | 管理员 | 编辑任意账单 | 管理所有数据 | 1. 可编辑任何成员的记录（记录者字段不可更改） |
| L-06 | 成员 | 删除自己的账单 | 移除错误记录 | 1. 只能删除自己创建的记录<br>2. 删除前二次确认 |
| L-07 | 管理员 | 删除任意账单 | 管理所有数据 | 1. 可删除任何成员的记录 |

## 详细功能说明

**功能描述**：家庭成员记录每笔收支，支持多维度查看和筛选。

**前置条件**：至少存在 1 个成员和 1 个分类。用户已登录。

**主流程**：
1. 用户点击「记一笔」按钮
2. 系统弹出记账表单，默认选中"支出"分类列表
3. 用户选择分类 → 输入金额(元) → 选择日期(默认今天) → 填写备注(可选，单行输入，最大200字符)
4. 系统校验：金额 > 0、分类存在
5. 系统从分类确定收支方向，记录者设为当前用户，保存记录
6. 列表刷新，新记录出现在对应日期分组中

**异常流程**：

| 异常场景 | 处理策略 |
|----------|----------|
| 金额为 0 或负数 | 前端拦截，提示"请输入正数金额" |
| 选择的分类已删除 | 后端返回 40004，前端提示"分类不存在" |
| 选择的成员已删除 | 后端返回 40004，前端提示"成员不存在" |
| 网络中断 | 前端提示"网络错误"，数据不丢失 |

**记账列表展示规则**：
1. 按日期分组展示，日期倒序排列（最新日期在上）
2. 日期格式：今天显示"今天"，昨天显示"昨天"，更早显示"M月D日 周X"
3. 每个日期分组显示当日支出小计
4. 月度收支小计（收入/支出/结余）固定在列表顶部（sticky），结余为负红色高亮
5. 每条记录显示记录者头像+姓名，体现协作记账的归属
6. 备注在列表中截断展示（超过30字符显示省略号），点击可查看完整内容

**后置条件**：记账记录持久化，仪表盘统计数据相应更新。

## 关联业务规则速查

- 金额存储：以"分"为单位，前端以"元"展示，详见 [BR-M01~BR-M05](../business-rules.md#83-金额规则)
- 收支方向：由关联分类 type **实时决定**，记录不存 type 字段，详见 [BR-T01~BR-T04](../business-rules.md#84-收支类型规则)
- 删除策略：软删除，详见 [BR-DL01](../business-rules.md#86-删除规则)
- 排序规则：按账单日期倒序（[BR-SO05](../business-rules.md#810-列表排序规则)）
- 备注最大 200 字符（[字段约束](../business-rules.md#811-字段约束)）
- 金额上限 999,999.99 元（[BR-M05](../business-rules.md#83-金额规则)）
