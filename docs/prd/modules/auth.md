# 认证与权限 — 模块需求

> 关联规则：[业务规则 - 权限规则](../business-rules.md#81-权限规则)、[业务规则 - 认证规则](../business-rules.md#82-认证规则)

## 用户故事

| ID | 角色 | 动作 | 价值 | 验收标准 |
|----|------|------|------|----------|
| A-01 | 管理员 | 首次初始化系统 | 建立暖屿 | 1. 首次访问进入初始化页面<br>2. 设置管理员账号（用户名+密码+姓名）<br>3. 创建第一个家庭成员（自己）<br>4. 初始化完成后自动登录<br>5. 管理员头像默认为 👨，可在个人中心修改 |
| A-02 | 成员 | 登录系统 | 进入自己的工作空间 | 1. 输入用户名+密码登录<br>2. 登录后进入仪表盘<br>3. 系统记住登录状态（7天） |
| A-03 | 成员 | 退出登录 | 保护账号安全 | 1. 点击退出，清除登录状态<br>2. 跳转到登录页 |
| A-04 | 管理员 | 为成员创建账号 | 让家人能独立登录 | 1. 添加成员时设置用户名+初始密码<br>2. 成员可用该账号登录<br>3. 管理员可重置成员密码 |
| A-05 | 成员 | 修改自己的密码 | 账号安全 | 1. 输入旧密码+新密码<br>2. 修改成功后需重新登录 |

## 详细功能说明

**功能描述**：用户登录/登出，基于角色的访问控制。

**主流程 — 初始化**：
1. 首次访问系统，检测无任何用户数据
2. 进入初始化页面，引导创建管理员账号（用户名+密码+姓名）
3. 系统创建管理员成员记录，关联账号
4. 系统自动创建预置数据：预置分类（支出15个+收入5个）、预置标签（10个）
5. 自动登录，进入仪表盘

**主流程 — 登录**：
1. 用户输入用户名+密码
2. 系统校验，签发 Token
3. 前端存储 Token，后续请求携带
4. 若使用默认密码，弹出提示"请修改密码"

**权限校验流程**：
1. 每个请求携带 Token
2. 中间件解析 Token，获取用户 ID 和角色
3. 管理员操作校验角色为 admin
4. 成员操作校验资源归属（只能编辑/删除自己的内容）

**异常流程**：

| 异常场景 | 处理策略 |
|----------|----------|
| 用户名或密码错误 | 提示"用户名或密码错误"，5次失败后锁定15分钟 |
| Token 过期 | 返回认证错误，前端跳转登录页 |
| 无 Token 访问受保护接口 | 返回认证错误 |
| 用户名已存在 | 提示"用户名已被使用"（创建时实时校验） |
| 非管理员访问管理员接口 | 返回权限不足错误，提示"权限不足" |
| 成员编辑他人资源 | 返回权限不足错误，提示"只能操作自己的内容" |
| 登录失败锁定 | 针对用户名锁定，5次失败后锁定15分钟自动解锁；管理员被锁定可通过命令行工具重置 |
