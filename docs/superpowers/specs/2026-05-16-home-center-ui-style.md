### 0.4 家庭化设计原则

| 原则 | 说明 | 落地方式 |
|------|------|----------|

### 1.5.2 触控区

- 所有可点击元素（按钮、列表项、Tab）最小触控高度 **44px**

### 1.5.3 页面边距

移动端页面内边距统一为 16px，与卡片内边距一致，保证视觉对齐。

## 3. 通用组件规范

### 3.1 空状态 `<EmptyState>`

已在技术设计文档 5.1 节完整定义。

### 3.2 成员头像

- 使用预置 emoji 列表（约 30 个），不支持自定义图片上传
- 默认头像：管理员 `👨`，成员 `👩`
- 尺寸：列表项 32px，详情/个人中心 64px，仪表盘卡片 40px
- 不带额外背景色或边框，直接显示 emoji 字符

### 3.3 角色标签

| 角色 | 标签色 | 标签文字 |
|------|--------|----------|
| 管理员 | 蓝色标签 | "管理员" |
| 普通成员 | 默认标签 | "成员" |
| 已禁用 | 灰色标签 | "已禁用" |

### 3.4 状态标签

**待办优先级**：

| 优先级 | Ant Design Tag 色 | 文字 |
|--------|-------------------|------|
| 紧急 | red | "紧急" |
| 重要 | orange | "重要" |
| 普通 | default | "普通" |

**待办状态**：

| 状态 | 展示 |
|------|------|
| 待办 | 未勾选复选框，日期正常显示 |
| 已完成 | 勾选复选框，文字加删除线灰色 |
| 过期（逾截止日期未完成） | 日期红色高亮 |

**愿望优先级**（复用待办优先级配色）：

| 优先级 | Ant Design Tag 色 | 文字 |
|--------|-------------------|------|
| 紧急 | red | "紧急" |
| 重要 | orange | "重要" |
| 普通 | default | "普通" |

**愿望状态**：

| 状态 | Ant Design Tag 色 | 文字 |
|------|-------------------|------|
| 待讨论 | default | "待讨论" |
| 已同意 | blue | "已同意" |
| 已实现 | green | "已实现" |
| 已放弃 | gray | "已放弃" |

**愿望归属**：

| 归属 | 标识 |
|------|------|
| 个人愿望 | 显示创建者头像+姓名，只读样式（无投票/操作按钮） |
| 家庭愿望 | 显示投票按钮和人数 |

**愿望分类**：

| 分类 | emoji 图标 |
|------|-----------|
| 物品 | 📦 |
| 旅行 | ✈️ |
| 体验 | 🎪 |
| 其他 | 💡 |

### 3.5 点赞与投票

- 点赞按钮：心形图标（`<LikeOutlined />`），已点赞高亮填充（`<LikeFilled />`）
- 投票选项：单选使用 radio，多选使用 checkbox
- 投票进度条：Ant Design `<Progress>`  带百分比显示
- 截止投票：选项不可选，仅显示结果

### 3.6 列表加载与分页

- 分页组件：Ant Design `<Pagination>`
- 每页 20 条，不提供分页大小切换（固定 20）
- 加载中：`<Skeleton>` 占位
- 加载更多：不采用滚动加载，仅分页

### 3.7 删除确认

所有删除操作统一使用 Ant Design `<Modal>` 二次确认：

```text
删除确认弹窗：
┌─────────────────────────────────────┐
│  ❓ 确认删除                        │
│                                     │
│ 确定要删除这条记录吗？此操作不可恢复。│
│                                     │
│        [取消]    [确认删除]          │
└─────────────────────────────────────┘
```

管理员删除他人数据时，提示文案改为：
```text
确定要删除 [成员名] 的这条记录吗？此操作不可恢复。
```

### 3.8 表单交互规范

#### 3.8.1 按钮层级

| 层级 | 样式 | 使用场景 |
|------|------|----------|
| 主要按钮 | Ant Design `type="primary"` | 保存、确认、记一笔、发动态 |
| 次要按钮 | Ant Design `type="default"` | 取消、清除筛选、重置 |
| 文字按钮 | Ant Design `type="link"` | 查看详情、编辑、页内跳转 |
| 危险按钮 | `danger` 属性 | 删除操作（红色文字/边框） |

#### 3.8.2 输入框状态

- **默认**：边框 `colorBorder`（#D9D9D9），浅灰背景
- **聚焦**：边框变品牌色，带轻微发光（Ant Design 默认行为）
- **错误**：边框变红色，下方显示红色错误提示文字
- **禁用**：背景变灰 #F5F5F5，文字变 `colorTextDisabled`（#BFBFBF）
- **成功**：输入合法后边框短暂变绿（500ms 后恢复默认）

#### 3.8.3 表单布局

- **桌面端**：单列布局，标签在输入框上方（非左侧），减少视觉扫描
- **移动端**：满宽输入，键盘弹出时表单自动上推
- **提交按钮**：始终固定在表单底部可见区域，或跟随页面滚动
- **标签对齐**：标签右对齐冒号（如"姓名："），输入框在标签下方

#### 3.8.4 金额输入

- 输入框自动调起数字键盘（`inputmode="decimal"`）
- 仅允许数字和小数点，保留两位小数
- 输入时自动加千分位分隔符（展示友好，提交时去除）
- 右侧固定显示"元"单位标签

#### 3.8.5 验证反馈

- **实时校验**：输入框失焦时触发（非输入过程中）
- **提交校验**：所有错误同时展示，不逐个报错
- **文案风格**：说"请填写标题"而非"标题不能为空"

### 3.9 加载状态

#### 3.9.1 页面加载

- **首次加载**（整页）：Ant Design `<Spin>` 居中显示，品牌色
- **列表加载**：`<Skeleton>` 占位（已在 3.6 定义）
- **局部加载**：内容区域半透明遮罩 + 顶部进度条
- **按钮提交**：按钮内显示加载图标，按钮本身禁用

#### 3.9.2 加载超时

- 按钮加载态最长 10 秒超时，超时后释放并提示"操作时间较长，请稍后查看"
- 短操作（< 300ms）不显示加载态，避免闪烁

### 3.10 通知反馈

| 类型 | 组件 | 展示位置 | 停留时间 | 使用场景 |
|------|------|----------|----------|----------|
| 成功 | `message.success()` | 顶部居中 | 3s 自动消失 | 保存成功、记账完成、待办勾选 |
| 错误 | `message.error()` | 顶部居中 | 5s 自动消失 | 操作失败、网络错误、权限不足 |
| 警告 | `notification.warning()` | 右上角弹窗 | 手动关闭 | 删除确认反馈、分类 type 变更影响提示 |

**文案风格**：

- 成功：`✅ + 动作 + 成功`，如 `✅ 记账成功`、`✅ 待办已完成`
- 错误：`❌ + 友好提示`，避免显示原始错误码，如 `❌ 网络开小差了，请稍后重试`

### 3.11 文案风格规范

#### 3.11.1 人称

- 系统称呼用户：**"你"**（非"您"），如"修改你的个人信息"
- 家庭成员之间：显示姓名，不显示角色标签之外的称谓
- 错误提示用"你"：如"你还没有权限操作"

#### 3.11.2 按钮文字

- 统一格式：**动词 + 对象**，如`记一笔`、`添加待办`、`发动态`
- 删除按钮始终加"确认"前缀：`确认删除`
- 不用纯名词：不写"保存"，写"保存分类"

#### 3.11.3 日期/时间格式

| 场景 | 格式 | 示例 |
|------|------|------|
| 账单日期 | 今天 / 昨天 / M月D日 周X | 5月16日 周四 |
| 待办截止 | M月D日 | 5月20日 |
| 时间戳 | HH:mm | 14:30 |
| 完整时间 | YYYY年M月D日 HH:mm | 2026年5月16日 14:30 |
| 年份省略 | 当年不显示年 | 5月16日（本月），12月25日（跨年） |

#### 3.11.4 时间相对化

- 1分钟内 → "刚刚"
- 1小时内 → "N分钟前"
- 今天内 → "HH:mm"
- 昨天 → "昨天 HH:mm"
- 更早 → "M月D日"

愿望清单在移动端不设独立 Tab，通过仪表盘页面内嵌"愿望动态"区域进入：
- 仪表盘页面下方展示愿望动态区域（最近 5 条愿望，按投票时间倒序）
- 点击任意愿望卡片跳转完整愿望列表页 `/wish`
- 愿望列表页顶部有返回按钮，返回仪表盘

## 5. 过渡与动画

- 页面切换：Ant Design 默认路由过渡，无自定义动画（保持简单）
- Modal/抽屉：Ant Design 默认动画
- 点赞切换：瞬间切换，无过渡动画
- 待办勾选：checkbox 切换，无动画
